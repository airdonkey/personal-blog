# 图片目录

## 需要添加的图片

### profile.jpg (必需)
- **用途**: 侧边栏头像
- **建议尺寸**: 300x300 像素
- **格式**: JPG 或 PNG
- **风格建议**: 
  - 专业形象照 (不要自拍)
  - 纯色或简洁背景
  - 正装或商务休闲装
  - 自然光线,避免过度修图

### 获取专业头像的途径

1. **专业摄影师**: 投资一次专业拍摄 ($100-500)
2. **AI 头像生成**: 使用 PhotoAI、HeadshotPro 等服务 ($29-99)
3. **自助拍摄**: 使用好光线 + 简洁背景 + 定时拍摄

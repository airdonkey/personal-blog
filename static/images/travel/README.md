# Grand Tour web images

Store only web-ready derivatives here, not original camera files.

- Keep originals in the private photo archive.
- Use stable, descriptive filenames prefixed by the journey slug.
- Remove private EXIF/GPS metadata before publishing.
- Prefer JPEG or WebP images no wider than 2400 pixels.
- Add meaningful alt text and captions in the journey entry.

If the collection eventually reaches thousands of images, the public URLs can be migrated to Cloudflare Images or R2 without changing the journey content model.
